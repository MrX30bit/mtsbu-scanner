СКАНЕР ОСЦПВ — PWA для iPhone

ОНОВЛЕННЯ НА GITHUB PAGES
1. У Safari відкрийте github.com/MrX30bit/mtsbu-scanner
2. Відкрийте вкладку Code. Через Add file → Upload files завантажте усі 7 файлів з архіву у корінь репозиторію (не в окрему папку):
   index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
3. Підтвердьте Commit changes. Замініть старий index.html, якщо GitHub запропонує.
4. Settings → Pages: Deploy from a branch, main, /(root).
5. Через кілька хвилин відкрийте https://mrx30bit.github.io/mtsbu-scanner/ у Safari.
6. Поділитися (квадрат зі стрілкою) → На початковий екран → Додати.
7. Запустіть іконку з екрана iPhone → Увімкнути камеру → Дозволити.

ВАЖЛИВО
- Додаток не є офіційним сервісом МТСБУ і не перевіряє поліси автоматично.
- Для OCR необхідне з’єднання з інтернетом (Tesseract.js завантажується із CDN).
- GitHub Pages — публічний хостинг, не розміщуйте службові ключі чи конфіденційні дані.
- Перевірте номер перед передачею до МТСБУ.
