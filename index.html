🎙️ Додаткове голосове введення

Останні розпізнані номери (лише в цій вкладці)

Результат з одного кадру може містити помилки. Перевіряйте номер перед використанням. OCR використовує бібліотеку Tesseract.js через інтернет. Голосове введення залежить від підтримки Web Speech API браузером; продиктований номер потрібно перевірити вручну. Звуковий сигнал відтворюється для нового розпізнаного номера, якщо звук увімкнено й Safari дозволяє аудіо. В автоматичному режимі номер показується після першого успішного зчитування (результат потрібно перевіряти вручну); інші типи та нестандартні номери можуть не розпізнаватися. Зображення обробляється в браузері; це не офіційна програма МТСБУ. Зум камери може бути апаратним або цифровим; 5× доступне не на всіх пристроях. Автофокусом на iPhone здебільшого керує iOS; вебзастосунок не може примусово гарантувати фокусування. Не використовуйте як доказ відсутності страховки. Не скануйте під час керування авто. Для доступу до камери потрібен HTTPS-сайт (звичайний відкритий HTML-файл на iPhone може не дати доступу).

Встановлення на телефон

iPhone: Safari → Поділитися → На початковий екран. Android: Chrome → меню ⋮ → Встановити додаток / Додати на головний екран. Камера потребує дозволу; для OCR потрібен інтернет.
